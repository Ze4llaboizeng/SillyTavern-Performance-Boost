Tips (ST official + mobile)
  • No Blur / Fast UI — User Settings → biggest jitter fix (ST FAQ).
  • Reduced motion — UI theme settings; kill cosmetic animations.
  • Streaming FPS 10–15 — lower = less paint while AI types.
  • # Messages to Load — paginate history (e.g. 40–80 on phones).
  • Hardware Acceleration — enable in the browser.
  • Disable heavy extensions — Live2D / VRM / talkinghead / big regex.
  • Termux host — performance.lazyLoadCharacters: true, useDiskCache: false in config.yaml.
  • Remote ST — run ST on PC/server; open the UI in the phone browser.
